■ 目的
用 menu 官方 setter 链（K3 实证直达捕获）逐轴定量测绘各底色的响应，
供 calibrate.py --matrix 求解每条配方的 (底座, 五轴) 最优组合。
数据质量直接决定配方区分度（OR1/YE1/YG1 偏弱问题的解决就靠这一轮）。

■ 前置（硬条件）
1. 卡上 \fpSup.BIN = **原版 USB shell 版**（绝不能是 v8——监视任务会
   抢模式/轴，污染测量）。AutoRun 不动。冷启动。
2. 全程**禁止进入 DUO 家族**（即便误触，立即 Color 切回 STD）。
3. fpsh 连通；命令单发、0x 前缀、超时 10-15s；禁 prom/adj/fwup；
   禁读 0x2E030000+；卡死拔电池。
4. 相机设置（拍前逐项核验）：
   - M 档手动曝光，ISO 100，光圈 f/4 左右，快门自定（拍屏不闪即可；
     若见条纹改 1/60 或 1/120）
   - 手动白平衡 5600K（锁死，禁 AutoWB）
   - JPEG 单张（不挂 DNG，省时）、尺寸 L、画质 FINE
   - 关防抖不是必须；三脚架固定，整个会话机身不许动
5. 测试图：把 D:\work\fp\tools\testchart.png 在显示器上**全屏 1:1 显示**
   （1920×1080，禁缩放/禁黑边适配），显示器关自动亮度、亮度适中，
   环境光稳定且不再变化。构图让测试图充满画面、横平竖直。

■ 第 0 步：快门触发通路测试（省 30 次按快门的机会）
  ./host/fpsh still
  → 若相机拍了一张 = 后续可用脚本驱动快门；不拍/报错 = 人工按快门，
    每步命令后等 ~1s 再按。

■ 主矩阵（33 张）
执行 D:\work\fp\dump\calib\manifest.json 对应的逐张清单——
**完整命令序列由 `python tools/gen_matrix.py` 打印**，核心规则：
  - 换底座：menu SetColorMode <序号>（0=STD 1=VIV 2=NTR 5=CINE 11=MONO）
  - 每换底座先核验五轴全 0（getter 读回；非 0 先清零——轴随模式记忆）
  - 每轴：set 档值 → 拍 → 归零，再下一轴
  - 顺序不可乱（manifest 按序绑定 SDIM 序号）
  - 每张记录"第 N 张 = SDIM 号"——其实只需记录**第 1 张的 SDIM 号**，
    后续按序顺推（拍摄中禁删片！删片会断序）
  - setter 应答应为 OK；任何非 OK 应答 = 停下来记录并回报
  - 拍摄间隔 ≥1s（写卡）；每 10 张目检一次屏幕确认状态未漂移

■ 收尾核验（全部归位）
  - 五个底座的五轴全 0（逐底座 getter 核验）
  - menu SetColorMode 回 STD（getter 读 0）
  - pic_color_mode 不动；无其他改动
  - 安全弹出 USB → 拔卡 → 全部 JPG 拷入 D:\work\fp\dump\calib\
    （manifest.json 已由 gen_matrix.py 预置在同目录）

■ 回传
  1. 第 1 张的 SDIM 号 + 总张数（应为 33）
  2. still 命令是否可用（决定下轮是否全自动）
  3. 任何非 OK 应答/异常现象原文
  4. （可选）STD 基线张与 photo19 基线张的观感差异一句话
