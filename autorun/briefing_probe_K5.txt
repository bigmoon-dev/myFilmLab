■ K5-1 活体电平矩阵（8 分钟，现场只管记录）
────────────────────────────────────────────────────────────
候选字（u32 各读一个）：
  W1=0xC3406050  W2=0xC3406058  F1=0xC3407414  F2=0xC340741C
  F3=0xC340903B  F4=0xC34090FB
（K5-0 的 diff 结果若给出新候选，主机侧会补发表——本轮先按此六字）
每键（AE、上、下；备用：左、右）× 两状态 × 10 轮：
  状态 R（松开）：mem get W1..F4 ×10 轮（间隔 ~200ms）
  状态 H（物理按住该键）：同上 ×10 轮
记录格式：键名 / 状态 / 轮次 / 六字原值（逐条照抄，不加工）
判定（回 PC 由主机侧做，标准预先写死）：
  H 态全部读数一致 且 ≠ R 态全部读数 → 合格电平位
  H 态读数递增 → 计数器，弃；H 态抖动 → 弃

■ K5-2 OSD 显示层实测（5 分钟，相机屏幕观察）
────────────────────────────────────────────────────────────
a) offset 语义（osdfile 第 6 参）：
  display osdfile \FILMLAB\T.BIN 0 0 1024 56 0
  → 屏幕顶部应出现彩色测试条+刻度数字。记录观感。
  display osdfile \FILMLAB\T.BIN 0 0 1024 56 2048
  display osdfile \FILMLAB\T.BIN 0 0 1024 56 112640
  → 各自画面出现在哪（下移一行？不变？报错？）逐条记录
b) 文字备份路线：
  display text FILMLAB
  → 字出现在屏幕何处？记录（v11 备选渲染路线的坐标基线）
c) 清层行为（作者警告复核）：
  display osd 1 0x00000000
  → 相机自身图标是否被清掉？多久自然恢复？（记录）
d) 重绘暂停/恢复（本简报唯一 mem set，作者 AutoRun 同款已验证操作）：
  mem set 0xC0528700 0xE12FFF1E     → UI 冻结？（记录）
  mem set 0xC0528700 0xE92D4BF0     → 恢复？（记录；如未恢复再发两次）
